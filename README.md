# The Excellent Management Consultancy

Premium React + Vite + Tailwind CSS website.

## Setup

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Features

- 8 pages (Home + 7 services)
- Dark luxury corporate design
- Fully responsive
- React Router navigation
- Framer Motion animations
- Contact links (phone, email, WhatsApp)

Built for UAE business consultancy.
